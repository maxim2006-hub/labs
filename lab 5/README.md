# Лабораторная работа 5: Регулярные выражения в Java

### Задание
Реализовать набор консольных утилит для поиска, валидации и модификации текстовых данных с использованием регулярных выражений (`java.util.regex`).

### Классы
* **WordFinder** – осуществляет поиск слов в тексте, начинающихся на заданную букву, игнорируя регистр символов.
* **PasswordChecker** – проверяет пароль на соответствие правилам безопасности (длина от 8 до 16 символов, обязательное наличие минимум одной цифры и одной заглавной буквы).
* **NumberFinder** – находит и извлекает из текстовой строки все целые и дробные числа.
* **IPAddress** – выполняет строгую проверку корректности IP-адреса с контролем числового диапазона (0–255).
* **CaseSwapper** – находит в тексте места, где строчная буква граничит с прописной, и выделяет эти группы символов.

### Ключевые паттерны и методы
* **Поиск в цикле:** Использование связки `matcher.find()` и `matcher.group()` для последовательного извлечения всех совпадений из текста.
* **Сложная валидация (Lookahead):** Применение опережающих проверок `(?=.*[0-9])(?=.*[A-Z])` для одновременной верификации нескольких условий в пароле.
* **Группировка и замена:** Использование регулярных выражений с круглыми скобками для создания групп захвата и обратных ссылок (`$1`) при вызове `matcher.replaceAll()`.
