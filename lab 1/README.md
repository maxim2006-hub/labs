# Лабораторная работа 1: Базовый синтаксис Java

### Задание
Создайте программу, которая находит и выводит все простые числа меньше 100, реализовать программу, которая определяет, является ли
введенная строка палиндромом.

## Содержимое репозитория

В репозитории представлены следующие классы:

* **JavaHelloWorldProgram** — базовая программа, которая выводит классическое приветствие "Hello World" в консоль
* **Palindrome** — приложение для проверки строк на палиндром, обрабатывающее переданные аргументы командной строки
* **Primes** — программа для поиска и вывода всех простых чисел в диапазоне от 2 до 100
