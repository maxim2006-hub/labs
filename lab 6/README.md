# Лабораторная работа: Коллекции и обобщенные типы данных в Java

### Задание
Реализовать решения задач, демонстрирующих работу со стандартными коллекциями Java Framework, создание кастомных обобщенных структур данных и применение потокобезопасных контейнеров для параллельной обработки.

### Классы
* **Stack<T>** – кастомная структура данных "Стек", реализованная с использованием обобщений (Generics) на базе фиксированного массива. Содержит методы добавления `push()`, извлечения `pop()` и просмотра верхнего элемента `peek()`.
* **TopWords** – утилита для подсчета статистики слов в текстовом файле. Выполняет чтение через `Scanner`, очистку слов регулярными выражениями, подсчет частоты и вывод топ-10 самых популярных слов.
* **SalesTracker** – менеджер учета продаж, использующий потокобезопасную карту `ConcurrentHashMap`. Поддерживает добавление записей, расчет общей выручки и поиск самого продаваемого товара.

### Ключевые коллекции и особенности
* **Ообобщенные типы (Generics):** Создание универсального класса `Stack<T>`, способного работать с любыми типами объектов с проверкой типов на этапе компиляции.
* **Частотный анализ (Map):** Применение `HashMap` и метода `getOrDefault()` для эффективного аккумулирования количества повторений строк.
* **Сортировка структур:** Преобразование ассоциативного массива в список `ArrayList<Map.Entry>` и его последующая сортировка по значениям (частоте) с помощью лямбда-выражения.
* **Потокобезопасность:** Использование `ConcurrentHashMap` для предотвращения состояния гонки (race condition) при фиксации торговых операций.
