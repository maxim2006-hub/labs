# Лабораторная работа 3: Структуры данных (Хэш-таблица)

### Задание
Реализовать универсальную структуру данных "Хэш-таблица" для хранения пар ключ-значение и продемонстрировать работу с записями на примере базы данных студентов.

### Классы
* **HashTable<K, V>** – кастомная хэш-таблица с поддержкой обобщений (Generics). Использует метод цепочек (массив списков `LinkedList`) для разрешения коллизий. Содержит методы `put()`, `get()`, `remove()`, `size()`, `isEmpty()` и приватный внутренний класс `Entry<K, V>`.
* **Student** – класс модели данных студента с полями `firstName`, `lastName`, `age`, `gpa` и переопределенным методом `toString()` для удобного вывода информации.
* **Main** – главный класс приложения, демонстрирующий выполнение базовых операций (вставка, поиск по ключу и удаление) над объектами студентов.

### Ключевые алгоритмы и особенности
* **Хэш-функция:** индекс бакета определяется через вычисление абсолютного значения остатка от деления хэш-кода ключа на емкость таблицы (`Math.abs(key.hashCode() % capacity)`).
* **Разрешение коллизий:** коллизии обрабатываются с помощью метода цепочек на базе `java.util.LinkedList`.
* **Управление элементами:** метод `put()` перезаписывает значение при совпадении ключа, а при его отсутствии добавляет новый элемент в список текущего бакета.
