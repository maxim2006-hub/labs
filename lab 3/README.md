# Лабораторная работа 3: Структуры данных (Хэш-таблица)

### Задание
Реализовать универсальную структуру данных "Хэш-таблица" для хранения пар ключ-значение и продемонстрировать работу с записями на примере базы данных студентов[cite: 12, 13].

### Классы
* **HashTable<K, V>** – кастомная хэш-таблица с поддержкой обобщений (Generics)[cite: 12]. Использует метод цепочек (массив списков `LinkedList`) для разрешения коллизий[cite: 12]. Содержит методы `put()`, `get()`, `remove()`, `size()`, `isEmpty()` и приватный внутренний класс `Entry<K, V>`[cite: 12].
* **Student** – класс модели данных студента с полями `firstName`, `lastName`, `age`, `gpa` и переопределенным методом `toString()` для удобного вывода информации[cite: 13].
* **Main** – главный класс приложения, демонстрирующий выполнение базовых операций (вставка, поиск по ключу и удаление) над объектами студентов[cite: 13].

### Ключевые алгоритмы и особенности
* **Хэш-функция:** индекс бакета определяется через вычисление абсолютного значения остатка от деления хэш-кода ключа на емкость таблицы (`Math.abs(key.hashCode() % capacity)`)[cite: 12].
* **Разрешение коллизий:** коллизии обрабатываются с помощью метода цепочек на базе `java.util.LinkedList`[cite: 12].
* **Управление элементами:** метод `put()` перезаписывает значение при совпадении ключа, а при его отсутствии добавляет новый элемент в список текущего бакета[cite: 12].
