# Лабораторная работа: ООП (Иерархия)

### Задание
Создать многоуровневую иерархию классов: Animal (абстрактный), Mammal, Bird, Fish, Cat, Parrot, Shark.

### Классы
* **Animal** – базовый абстрактный класс с полями `name`, `age`, `gender` и статическим счётчиком `objectCount`. Содержит абстрактный метод `makeSound()`, геттеры/сеттеры и общий метод `eat()`.
* **Mammal** – расширяет Animal, добавляет поля `furColor`, `isWild`, `runSpeed`. Переопределяет `makeSound()`, содержит метод `run()`.
* **Bird** – расширяет Animal, добавляет поля `wingSpan`, `canFly`. Переопределяет `makeSound()`, содержит метод `fly()`.
* **Fish** – расширяет Animal, добавляет поля `waterType`, `maxDepth`. Переопределяет `makeSound()`, содержит метод `swim()`.
* **Cat** – наследуется от Mammal, добавляет поля `breed`, `isIndoor`, `livesLeft`. Переопределяет `makeSound()`, содержит перегруженный метод `scratch()` и метод `displayInfo()`.
* **Parrot** – наследуется от Bird, добавляет поле `wordsKnown`. Переопределяет `makeSound()`, содержит перегруженный метод `speak()`.
* **Shark** – наследуется от Fish, добавляет поле `toothCount`. Переопределяет `makeSound()`, содержит метод `hunt()`.

### Демонстрация ООП
* **Абстракция:** класс `Animal` объявлен как `abstract`, метод `makeSound()` не имеет реализации в базовом классе.
* **Инкапсуляция:** все свойства классов скрыты (`private`), доступ к ним реализован через публичные геттеры и сеттеры.
* **Наследование:** промежуточные и конечные классы расширяют функционал родительских с помощью ключевого слова `extends`.
* **Полиморфизм:** переопределение метода `makeSound()` в дочерних классах, перегрузка методов `speak()` и `scratch()`, а также создание полиморфного массива `Animal[] zoo`.
