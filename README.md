# лабораторные работы по Java

Данный репозиторий содержит комплекс выполненных лабораторных работ по изучению синтаксиса, концепций объектно-ориентированного программирования (ООП), структур данных, встроенных механизмов и продвинутых возможностей языка Java.

---

## 📂 Структура репозитория

* **[Лабораторная работа №1](https://github.com/maxim2006-hub/labs/tree/main/lab%201) — Базовый синтаксис**
  * Вводные программы для знакомства с компиляцией и запуском через CLI. Решения задач на циклы, условия и простые алгоритмы обработки строк.
  * **Ключевые файлы:** `JavaHelloWorldProgram.java`, `Primes.java`, `Palindrome.java`.

* **[Лабораторная работа №2](https://github.com/maxim2006-hub/labs/tree/main/lab%202) — Объектно-ориентированное программирование**
  * Проектирование иерархии классов на примере предметной области «Мебель». Реализация абстрактных классов, инкапсуляции, наследования и полиморфизма.
  * **Ключевые файлы:** `Furniture.java` (базовый класс), `Table.java`, `Chair.java`, `Bed.java`, `Main.java`.

* **[Лабораторная работа №3](https://github.com/maxim2006-hub/labs/tree/main/lab%203) — Структуры данных**
  * Разработка собственной параметризованной хэш-таблицы с разрешением коллизий методом цепочек. Применение структуры в мини-системе учета персонала.
  * **Ключевые файлы:** `HashTable.java`, `EmployeeManagement.java`.

* **[Лабораторная работа №4](https://github.com/maxim2006-hub/labs/tree/main/lab%204) — Исключения и Ввод-Вывод**
  * Обработка стандартных и кастомных исключений с помощью блоков `try-catch` и конструкции `try-with-resources`. Реализация побайтового копирования файлов и ведение логов ошибок в текстовый файл.
  * **Ключевые файлы:** `ArrayAverage.java`, `FileCopier.java`, `MathCalculator.txt`.

* **[Лабораторная работа №5](https://github.com/maxim2006-hub/labs/tree/main/lab%205) — Регулярные выражения**
  * Использование классов `Pattern` и `Matcher` для валидации, поиска и модификации текстов. Проверка безопасности паролей, валидация IPv4-адресов, парсинг чисел и замена строк.
  * **Ключевые файлы:** `IPAddress.java`, `PasswordChecker.java`, `NumberFinder.java`.

* **[Лабораторная работа №6](https://github.com/maxim2006-hub/labs/tree/main/lab%206) — Коллекции и многопоточные контейнеры**
  * Создание кастомного обобщенного `Stack<T>`. Работа с Java Collections Framework. Частотный анализ текста (Топ-10 слов) и создание потокобезопасного трекера продаж на базе `ConcurrentHashMap`.
  * **Ключевые файлы:** `Stack.java`, `TopWords.java`, `SalesTracker.java`.

* **[Лабораторная работа №7](https://github.com/maxim2006-hub/labs/tree/main/lab%207) — Многопоточное программирование**
  * Параллельная обработка массивов и матриц с распределением данных между потоками. Использование пулов потоков (`ExecutorService`, `Callable`, `Future`) и синхронизаторов (`CountDownLatch`).
  * **Ключевые файлы:** `ArraySumTask.java`, `MatrixMaxFinder.java`, `WarehouseApp.java`.

* **[Лабораторная работа №8](https://github.com/maxim2006-hub/labs/tree/main/lab%208) — Создание приложения**
  * Разработка пользовательской аннотации `@DataProcessor` для маркировки методов и их динамический вызов через рефлексию (Reflection API). Реализация параллельной обработки данных с использованием `parallelStream()` и асинхронное выполнение через `ExecutorService` и `Future`.
  * **Ключевые файлы:** `Main.java`.

---

В ходе выполнения работ были освоены и применены следующие механизмы языка Java:
1. **ООП:** Абстрактные классы и интерфейсы, полиморфизм времени выполнения, сокрытие данных.
2. **Алгоритмы и структуры:** Хэширование, обход цепочек связанных списков, управление динамической памятью (LIFO в кастомном стеке).
3. **Безопасность типов:** Обобщения (Generics) для создания универсальных переиспользуемых контейнеров.
4. **Многопоточность (Concurrency):** Синхронизация критических секций, безопасные коллекции для конкурентной среды, управление потоками через пулы задач.
5. **Метапрограммирование:** Инспекция структуры классов, чтение аннотаций в рантайме и динамический инвоук методов.
