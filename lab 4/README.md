# Лабораторная работа: Обработка исключений и файловый ввод-вывод

### Задание
Решения задач, демонстрирующих механизмы обработки исключений (Exception Handling), работу с потоками ввода-вывода (I/O Streams) и логирование ошибок в файлы.

### Классы и файлы
* **ArrayAverage** – программа для вычисления среднего арифметического элементов строкового массива. Демонстрирует перехват стандартных ошибок преобразования данных (`NumberFormatException`) и выхода за границы коллекции (`ArrayIndexOutOfBoundsException`).
* **FileCopier** – утилита для побайтового копирования содержимого из `source.txt` в `destination.txt` через `FileInputStream` и `FileOutputStream`. Реализует безопасное закрытие потоков внутри блока `finally`.
* **DivisionLogger** – приложение, содержащее метод деления чисел с генерацией кастомного исключения `CustomDivisionException`. Включает метод `logException()` для записи трассировки ошибок в файл `exception_log.txt` с отметкой времени.

### Особенности обработки ошибок
* **Мультиперехват (Multi-catch):** Использование последовательных блоков `catch` для раздельной обработки различных типов угроз в одном блоке выполнения.
* **Гарантированное выполнение (Finally):** Применение конструкции `finally` для освобождения системных ресурсов и закрытия файловых дескрипторов вне зависимости от возникновения ошибок.
* **Пользовательские исключения:** Создание собственного класса ошибок путем расширения базового класса `Exception` и принудительный вызов через оператор `throw`.
* **Try-with-resources:** Использование современного синтаксиса для автоматического закрытия объектов `PrintWriter` и `FileWriter` при логировании.
