# Лабораторная работа 7: Многопоточное программирование в Java

### Задание
Реализовать параллельные вычисления и потокобезопасное управление ресурсами с использованием базовых потоков `Thread` и фреймворка Fork/Join.

### Классы и задачи
* **Task1 (SumThread)** – выполняет параллельное суммирование элементов числового массива. Массив делится пополам, и каждая половина обрабатывается в отдельном потоке.
* **Task2 (MaxThread)** – находит максимальный элемент в двумерной матрице. Для обработки каждой строки матрицы создается и запускается индивидуальный поток.
* **Task3 (TransferTask & LoadingZone)** – симулирует распределенную погрузку товаров на склад. Использует Fork/Join для рекурсивного деления задач и `synchronized`-методы для защиты общих данных.

### Особенности параллельного программирования
* **Управление жизненным циклом (Start & Join):** Запуск параллельного выполнения через метод `start()` и явное ожидание завершения расчетов с помощью `join()` для предотвращения преждевременного вывода результата.
* **Фреймворк Fork/Join (RecursiveAction):** Реализация принципа «разделяй и властвуй». Задачи рекурсивно расщепляются на подзадачи, пока их размер не станет меньше заданного порога (`THRESHOLD`), после чего они выполняются пулом потоков.
* **Потокобезопасность (Thread Safety):** Использование ключевого слова `synchronized` в классе `LoadingZone` для предотвращения состояния гонки (race condition) при одновременном изменении веса в фургоне разными потоками.
